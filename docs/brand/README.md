# Ritom Music brand assets

The symbol is an iPod click wheel (menu, previous, next, play/pause) whose centre button holds a sound wave.

| File | Use |
|---|---|
| `symbol.svg` / `symbol-512.png` | full-colour symbol on its gradient tile (app, avatars, README) |
| `symbol-black.svg` / `symbol-black-512.png` | single colour, for light backgrounds |
| `symbol-white.svg` / `symbol-white-512.png` | single colour, for dark backgrounds |
| `social-preview.png` | 1280×640 GitHub social preview (Settings → General → Social preview) |

Colours: gradient `#FA5C6B` → `#8C2ECC`, white `#FFFFFF`, ink `#111111`.
